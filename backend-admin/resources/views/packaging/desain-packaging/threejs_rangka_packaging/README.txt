3D RANGKA & PENUTUP PACKAGING KAYU – V3
=========================================

CARA MEMBUKA
1. Ekstrak file ZIP.
2. Klik dua kali "BUKA_APLIKASI.bat" atau buka "index.html".
3. index.html bekerja tanpa internet.

FITUR RANGKA
- Input Panjang, Lebar, dan Tinggi dalam mm.
- Ukuran balok rangka dan balok penyangga.
- Jarak maksimum untuk jumlah penyangga otomatis.
- Penyangga terpisah untuk sisi Depan, Belakang, Kanan, Kiri, Atas, dan Bawah.
- Orientasi penyangga Horizontal atau Vertikal.
- Jumlah penyangga otomatis atau manual 1, 2, atau 3.

FITUR PENUTUP BARU
- Jenis penutup per sisi:
  1. Papan Setengah: papan diberi celah.
  2. Papan Full: papan disusun rapat tanpa celah.
  3. Triplex: satu lembar penuh.
- Setiap sisi dapat diaktifkan atau dinonaktifkan secara terpisah.
- Arah papan Horizontal atau Vertikal dapat dipilih khusus untuk setiap sisi.
- Pengaturan lebar papan, tebal papan, celah Papan Setengah, dan tebal Triplex.
- Ringkasan jumlah potongan penutup dan luas penutup.

ARAH PENUTUP
- Depan/Belakang: Horizontal = arah panjang; Vertikal = arah tinggi.
- Kanan/Kiri: Horizontal = arah lebar; Vertikal = arah tinggi.
- Atas/Bawah: Horizontal = arah panjang; Vertikal = arah lebar.
- Untuk Triplex, arah tidak mengubah bentuk karena tetap satu lembar penuh.

TAMPILAN
- Isometrik, Depan, Kanan, dan Atas.
- Putar menggunakan klik dan tarik.
- Zoom menggunakan scroll mouse.
- Tampilkan/sembunyikan dimensi dan grid.
- Simpan tampilan sebagai PNG.

FILE
- index.html: versi offline yang paling stabil.
- index_threejs_online.html: versi Three.js melalui CDN; membutuhkan internet.
- offline-fallback.js: renderer offline.
- app.js: logika versi Three.js online.
- BUKA_APLIKASI.bat: pembuka cepat Windows.
